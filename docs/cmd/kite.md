## kite

kite - 网易云接口 CLI

### Synopsis

kite - 接口调试与实用工具

直连 engine + endpoint 声明,不经 gRPC/gateway。
登录态接口需先 login(扫码)或 login-cellphone(手机号验证码)。

登录态来源:
  1. 环境变量 NETEASE_COOKIE(优先,用于临时换号调试)
  2. 本地配置目录的 session.json(login 写入,logout 删除);
     路径见 kite doctor(macOS: ~/Library/Application Support/kite/ 等)

```
kite [flags]
```

### Options

```
  -h, --help           help for kite
      --help-verbose   列出全部命令(不分组)
      --json           以 JSON 输出(管道/重定向时自动启用)
      --proxy string   HTTP/SOCKS5 代理(如 http://127.0.0.1:7890);压过 config 与环境变量
      --yes            写操作跳过 y/N 确认(脚本场景)
```
